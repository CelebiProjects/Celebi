Navigation & File Management
============================

These commands provide a filesystem-like interface. ``cd`` and ``cd-project``
are interactive-shell commands; their directory changes cannot be preserved by a
one-shot ``celebi-cli`` child process.

* ``ls`` – List directory contents
* ``cd`` – Change directory
* ``mkdir`` – Create a directory
* ``cp`` – Copy files or directories
* ``mv`` – Move or rename files or directories
* ``rm`` – Remove files or directories
* ``cat`` – Display file contents
* ``ls-projects`` – List available projects in the interactive shell
* ``cd-project`` – Switch active project in the interactive shell
* ``list-projects`` – List registered projects with ``celebi-cli``
* ``use-project`` – Select the project opened by the next ``celebi`` session
* ``project-path`` – Print the current project path
* ``project-uuid`` – Print the current project's stable UUID
